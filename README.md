This project classifies company annual reports based on whether they disclose Scope 1, Scope 2, and Scope 3 greenhouse gas emissions, using three main scripts: scraper_script.py to collect reports and extract text, make_dataset.py to build a labelled dataset (dataset.csv) using simple heuristics where reports mentioning Scope 1, 2, and 3 are labelled 1 and those mentioning only Scope 1 and 2 (or planning Scope 3 in the future) are labelled 0, and training_script.py which trains a TF-IDF + Logistic Regression model and prints a JSON summary with training details and evaluation metrics. To run the project, open the folder in PowerShell, create a virtual environment with python -m venv .venv and activate it using .venv\Scripts\activate, install dependencies with pip install -r requirements.txt, then if validation.csv does not exist create it from the dataset with python -c "import pandas as pd; df=pd.read_csv('dataset.csv'); df.sample(n=50, random_state=42).to_csv('validation.csv', index=False)", and finally execute python training_script.py --validation validation.csv to see the output JSON containing files used for training, exchanges in the dataset, and accuracy, precision, recall, and f1 score.
